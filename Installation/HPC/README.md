# MTD Explorer node installation

The scripts in this directory independently prepare node-local software and
databases for the [MTD Explorer](https://github.com/patrick-douglas/MTD-Explorer)
[Slurm](https://slurm.schedmd.com/) backend.

They do not clone or require
[HpcGridRunner](https://github.com/patrick-douglas/HpcGridRunner) or
[AutoHPC](https://github.com/patrick-douglas/AutoHPC).

See [`README_MTD_HPC.md`](../../README_MTD_HPC.md) for installation, node-list,
database synchronization, configuration, and validation instructions.
